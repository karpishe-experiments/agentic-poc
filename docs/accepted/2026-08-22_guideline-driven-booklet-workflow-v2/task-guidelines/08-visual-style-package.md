# Guideline — Generating a Visual Style Package

## Purpose

Define and validate the reusable visual language for the book after the story, final character records, and final location records are approved. This artifact establishes how the book looks; it does not design a particular page or replace a character/location source record.

## Required inputs

- Approved Book Concept Brief, Story Outline, Page-by-Page Manuscript, Final Character List, and Final Location List.
- User-provided visual references, style requests, and technical constraints.

## Method and rules

1. If the visual direction is open, propose two to four distinct, concise options and ask the user to choose or combine them.
2. Write a human-readable Style Definition and a reusable Style Prompt Module. The prompt module is injected unchanged into every sheet and final page request.
3. Define typography direction and visual treatment of narration, speech bubbles, thought bubbles, sound effects, and diegetic text. The Pagination & Layout Plan later turns this direction into a physical-page typography system and font choice.
4. Generate two to four non-final validation samples that test emotion, environment, action, and detail/prop readability. Record each test purpose and exact assembled prompt.
5. Do not lock a final page composition, a character's individual identity, a location's individual geometry, or exact page text.
6. Present samples and the package for explicit approval. Revise only affected elements after feedback.

## Quality gate

- The style is coherent, age-appropriate, original, and readable.
- Text and bubble direction is usable by pagination and final-page work.
- The approved shared module, validation samples, and records are preserved as reusable references.
