# Guideline — Generating a Final Character List

## Purpose

Create the approved production source for every character required by the approved manuscript. This is the single current character reference for later visual style, Character Sheet Packages, page planning, and final page generation.

## Required inputs

- Approved Page-by-Page Manuscript.
- Approved Draft Character List and Story Outline.
- Relevant user decisions from chat context.

## Required artifact

```markdown
# Final Character List — [Working Title]

**Status:** Draft awaiting approval
**Based on:** [approved manuscript and narrative sources]

| ID | Name or role | Narrative role | Pages / scenes | Background | Age or life stage | Physical description | Personality and acting notes | Attire requirements | Distinct accessories | Recurrence | Character-sheet requirement | Open decisions |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

## Character Profile Guidance
## Representation and Continuity Rules
## Approval Gate
```

## Method and rules

1. Derive the complete cast from the approved manuscript, including named roles and stable functional roles such as `Passer-by 01` where needed.
2. Give each character a concise background, age or life stage, physical description, personality/acting guidance, and all information needed to draft a Character Design Profile.
3. A character requires a Character Sheet Package when it recurs in more than one scene. The creator may explicitly request a sheet for any additional character.
4. Record multiple attire only when the manuscript, this list, or an explicit later user decision requires it. Each required attire is a named continuity requirement and needs an appropriate sheet or sheet section.
5. Do not decide shared visual style here; leave artistic rendering to the Visual Style Package. Do not write page-specific poses or compositions.
6. When a sheet-review revision changes a character fact, revise this Final Character List first or in the same scoped revision, then regenerate and reapprove the affected sheet.

## Quality gate

- Every manuscript character is recorded once with a stable ID/name or role.
- Recurrence and sheet requirements are explicit.
- The list is detailed enough to guide a profile, while remaining separate from shared visual style and page composition.
