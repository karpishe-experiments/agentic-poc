# Guideline — Generating a Character List

**Paired artifact:** Character List  
**Use:** After the Page-by-Page Manuscript is approved and before any new individual character package is created.

## Required Inputs

- Approved Page-by-Page Manuscript
- Approved Story Outline
- Existing approved character packages, if any

## Method

1. Extract every named and unnamed role from the manuscript.
2. Record each role’s pages, narrative purpose, relationship to the protagonist, and recurrence.
3. Reuse approved character packages when they already satisfy the manuscript.
4. Route only high-continuity or visually recurring characters to an Individual Character Package.
5. Keep page-only and background figures open for later page illustration direction.

## Required Output

A human-readable table containing character, role, pages, continuity need, and design routing, followed by relationship notes and an approval gate.

## Quality Checks

- Every named character in the manuscript appears in the list.
- No new wardrobe, appearance, setting, or style details are invented here.
- Existing approved character packages are not duplicated or silently altered.
- One-off figures are not promoted to individual packages without a real continuity need.

## Common Failures

- Designing characters before the manuscript determines whether they are needed.
- Treating all background figures as a fixed cast.
- Adding a new individual package for an already approved character.
- Contradicting approved physical-continuity rules, including a character’s missing limb.
