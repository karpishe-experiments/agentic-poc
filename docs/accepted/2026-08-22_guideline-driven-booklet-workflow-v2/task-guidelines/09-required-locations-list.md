# Guideline — Generating a Required Locations List

**Paired artifact:** Required Locations List  
**Use:** After the Page-by-Page Manuscript is approved, before any Location Definition Package is created.

## Required Inputs

- Approved Page-by-Page Manuscript
- Approved Character List
- Existing approved location packages, if any

## Method

1. Extract every place where a manuscript page occurs.
2. Merge places only when they are truly one reusable environment.
3. Record pages, required story functions/props, recurrence, and the required level of visual continuity.
4. Route high-continuity locations to Location Definition Packages.
5. Leave one-off places as page-level setting direction unless a later layout decision creates a continuity need.

## Required Output

A human-readable table containing each location, pages, story requirement, continuity need, and routing, followed by clear location boundaries and an approval gate.

## Quality Checks

- Every manuscript setting is represented once.
- Location packages are limited to settings with actual continuity needs.
- No speculative world-building is added.
- Location definitions remain neutral about time, weather, lighting, action, text-safe space, and composition.

## Common Failures

- Creating a broad world guide before the manuscript identifies its locations.
- Splitting one reusable place into redundant packages.
- Treating a transition route as a fixed setting without a later continuity need.
- Allowing location definitions to override page-specific art direction.
