# Guideline — Generating a Final Location List

## Purpose

Create the approved production source for every location in the approved manuscript. This is the single current location reference for later visual style, Location Sheet Packages, page planning, and final page generation.

## Required inputs

- Approved Page-by-Page Manuscript.
- Approved Draft Location List and Story Outline.
- Relevant user decisions from chat context.

## Required artifact

```markdown
# Final Location List — [Working Title]

**Status:** Draft awaiting approval
**Based on:** [approved manuscript and narrative sources]

| ID | Location title | Pages / scenes | Story purpose | Basic description | Stable environmental anchors | Required props or features | Continuity notes | Location-sheet requirement | Open decisions |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

## Location Profile Guidance
## World, Safety, and Accessibility Rules
## Approval Gate
```

## Method and rules

1. Derive every manuscript location and give it a stable title and basic description that lets a person imagine the place.
2. Record story purpose, stable anchors, required recurring features, accessibility/safety needs, and continuity notes.
3. Every location in this approved list requires a Location Sheet Package. If the creator later adds a location, revise this list before generating its sheet.
4. Keep page-specific action, weather, lighting, time of day, panel layout, composition, and text placement out of the list unless the manuscript makes a fact narratively permanent.
5. When a sheet-review revision changes a location fact, revise this Final Location List first or in the same scoped revision, then regenerate and reapprove the affected sheet.

## Quality gate

- Every manuscript place has one clear entry.
- A creator and agent can imagine each place from its title and description.
- The list provides stable production context without becoming a page illustration brief.
