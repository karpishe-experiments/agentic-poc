# Guideline — Generating a World / Setting Guide

**Artifact guideline:** 06  
**Status:** Draft reusable guideline — awaiting approval

## Objective

Create a controlled, reusable setting reference that makes later scenes feel physically and socially connected. It defines stable world information only. It must not turn into a page-illustration brief, visual-style rewrite, map without need, or a substitute for character packages.

## Required Inputs

- Approved Book Concept Brief and Story Outline;
- approved Character List and any approved Individual Character Packages;
- approved Visual Style Definition and Visual Style Prompt Module;
- audience age range and story safety boundaries;
- any user-supplied place, cultural, geographic, or accessibility requirements.

## Required Outputs

1. **World / Setting Guide** — human-readable reference, marked Draft awaiting approval until explicitly approved.
2. **Approval / Version Record** once approved.

The World / Setting Guide does not require a shared prompt module. Page Illustration Packages create their own page-specific location and composition module, then inject the approved Visual Style Prompt Module unchanged.

## Agent Workflow

1. Read predecessor artifacts. Extract story-required locations, social conditions, safety boundaries, character needs, and any already-approved names.
2. Identify only the locations needed for the current story. Do not overbuild a fictional encyclopedia or map the entire city when a neighbourhood-scale setting is sufficient.
3. If a setting identity is materially open, propose 2–4 short directions. If the user has already provided a clear setting direction, draft directly from it.
4. Draft the guide with the controlled template below. Separate stable setting facts from page-specific decisions.
5. Make every named location legible through a few repeatable physical cues, usable routes, and child-scale spatial logic.
6. Apply representation requirements to the setting: it should support each character’s ordinary participation without treating disability or difference as an obstacle that requires a magical fix.
7. Keep the approved art style out of the setting authoring content. State only setting-specific visual rules that do not duplicate the Visual Style Definition.
8. Present the guide as **Draft awaiting approval**. Capture focused questions only for decisions that materially affect later pages.
9. On approval, save the final guide and guideline as canonical artifacts. Do not retain superseded drafts as co-equal source documents.

## Boundary Rules

- The guide may define location identity, geography, architecture, environmental details, social atmosphere, and stable recurring cues.
- It must not define time of day, weather, light source, camera position, exact page composition, character pose, text-safe area, or story action. Those belong in a later page-specific prompt module.
- It must not restate the shared Visual Style Prompt Module. The module is injected unchanged only when images are generated.
- Do not use named franchise cities, recognisable landmarks, logos, readable signs, or copied environmental iconography.
- Preserve the target age’s emotional safety: do not make the setting frightening merely to make it feel dramatic.

## Quality Checks

- Every core story event has a plausible, clearly staged location.
- Locations share enough recurring cues to feel like one world while retaining distinct functions and silhouettes.
- The scale works for the protagonist’s age and the story’s action.
- Setting detail supports story readability rather than competing with it.
- No representation requirement is converted into a barrier, cure narrative, or visual gimmick.
- Stable setting facts and page-specific decisions are cleanly separated.

## Common Failures

- Writing a page illustration brief instead of a reusable guide.
- Baking a preferred time of day, weather pattern, or story beat into the world identity.
- Copying the visual style description into the setting guide.
- Creating a grim, unsafe, or adult-scale setting for a young child’s story.
- Adding a large number of locations that never serve the story.
- Using readable signage or brand references that cannot safely appear in generated art.
