# Guideline — Generating a Pagination & Layout Plan

## Purpose

Turn the approved manuscript and visual-reference sources into an approved plan for the physical book before exact page compositions or final images are created. This artifact locks the global page system that every final image must follow.

## Required inputs

- Approved Page-by-Page Manuscript, Final Character List, Final Location List, Visual Style Package, and all required Character and Location Sheet Packages.
- User requirements for trim, print method, language direction, or publisher constraints, if any.

## Method and rules

1. Lock one physical canvas: trim, orientation, aspect ratio, working pixels, bleed, and safe margins. Every generated page must use it.
2. Select and document the exact font or an approved font family/direction, text hierarchy, and visual treatment for narration, speech, thought, sound effects, titles, credits, and diegetic text. Ensure the choices conform to the approved Visual Style Package.
3. Map the manuscript to each physical page, including cover, front matter, story pages, closing matter, and back cover. State whether a page uses one image or multiple panels/images.
4. Reserve text-safe areas and panel/image allocation, but leave exact action composition and exact text for the Final Page Bible.
5. Route every page to the approved character and location sheets it needs.
6. Do not alter the approved manuscript's story order or prose to force a page count; return a narrative change to its owning specialist for approval.

## Quality gate

- Every physical page has one compatible canvas and a clear role.
- Font, text/bubble system, panel count, and text-safe rules are explicit.
- All required approved sheets are available and correctly routed.
- No page illustration is generated before this artifact is approved.
