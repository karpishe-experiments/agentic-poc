# Guideline — Generating an Individual Character Sheet Package

## Purpose

Create one approved visual-reference package for each character marked as requiring a sheet in the Final Character List. The sheet is a reusable continuity source for final pages, not generic concept art.

## Required inputs

- Approved Final Character List entry for the target character.
- Approved Visual Style Package and unchanged Style Prompt Module.
- Relevant user decisions and any already-approved character sheets for cast contrast.

## Required artifact per character

```markdown
# Individual Character Sheet Package — [Character ID]

**Status:** Draft awaiting approval
**Based on:** [Final Character List version and Visual Style Package version]

## Character Design Profile
## Required Attire and Accessory Variants
## Required Expression Set
## Character-Sheet Prompt Module
## Assembled Generation Prompt and Reference Record
## Character Sheet Image
## Review, Approval, and Version Record
```

## Sheet requirements

Every Character Sheet Image must include:

1. a full-body front view;
2. a full-body back view;
3. a full-body side view;
4. a neutral facial view with clear physical detail; and
5. three additional facial-expression shots defined by the Final Character List or an explicit creator prompt.

Include distinct accessories when the Final Character List requires them. Include each explicitly required attire as a separately clear view or sheet section; do not invent extra outfits.

## Method and rules

1. Confirm the target has a stable list entry and requires a sheet. Ask focused questions if the list cannot support a clear profile, required expressions, or attire.
2. Draft a character-specific profile and module without restating the shared style module.
3. Compare the character with the approved cast to avoid accidental visual duplication.
4. Generate the sheet from the unchanged shared Style Prompt Module plus the character-specific module.
5. Present the sheet for approval. If feedback changes a stable character fact, update the Final Character List and this package together before regenerating.
6. Keep one current approved sheet version per character/attire requirement and preserve the build record for every approved version.

## Quality gate

- All required views, expressions, attire, and accessories are present and legible.
- The character is consistent with the Final Character List and distinguishable from the cast.
- The sheet has no labels, watermarks, unrelated characters, extra limbs, or unapproved attire.
