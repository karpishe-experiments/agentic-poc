# Experiment brief

Copy this file for each experiment and replace the prompts below.

## Experiment

**Name:**  
**Hypothesis:** What idea should this experiment prove or disprove?

## User experience

Describe the user journey or interaction to demonstrate.

## Success criteria

- State the observable conditions that make the experiment successful.

## Scope

**In scope**

- List the behavior this experiment must include.

**Out of scope**

- List nearby behavior that should not be implemented.

## Technical constraints

Document the preferred stack, required integrations, dependency limits, or other constraints. If no stack is required, say so.

## Risks and open decisions

- Record known risks and decisions that must be resolved during planning.

## Verification

- List the checks or scenarios that demonstrate the success criteria.
