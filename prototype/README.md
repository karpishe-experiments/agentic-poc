# Kid Comics prototype

This folder contains the local React/Vite prototype for the Kid Comics agentic generative-UI experiment.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL. The prototype starts with a genuinely empty new booklet. Testers can load the explicit Milo demo idea, send it, and walk through the agent-guided artifact creation flow.

## Included

- React + TypeScript + Vite app source
- ShadCN-style UI primitives and Tailwind styling
- Milo story package and supplied visual assets
- Dynamic artifact rail and Markdown-rendered text artifacts
- GenUI inquiry drawers with simulated agent processing

Generated dependencies and build output are intentionally excluded from this experiment folder.
